# The Long Century · Game review and implementation plan

**Edition reviewed:** Cabinet and Crisis, 1836–1936. **Deliverable:** planning only, 19 November 2026.

**Recommendation.** Keep the monthly simulation and the full dashboard. First make every screen tell the truth about what an order will do. Then make the first screen answer three questions: What needs me now? What changed since I last played? Where can I act? Add historical and political depth once the player can see its consequences.

## What the current game does well

The release starts with 62 countries and 184 provinces. It already has household needs and class politics, a market with 31 goods, 69 technologies, 25 province-building types, a Works queue, theatres and naval stations, diplomacy, historical choices and a campaign-end chronicle. Cabinet agendas, annual reports, choice-triggered pauses, and advances of 3, 6 or 12 months are working foundations. Preserve the short, selectable decisions, period look, one-file offline game and Android Firefox support. Keep the £100 million cheat in Settings. Build from the Cabinet and Crisis source ZIP. The old docs/plans/PLAN.md contains completed work alongside its backlog.

## What the review established

I inspected the released HTML and its matching source archive. I ran the existing historical, save-compatibility and theatre checks and exercised the released JavaScript in isolated game states. The four focused test scripts passed. An all-AI simulation on seed 7 reached January 1936 at 98.4 ms per month on the review machine. Germany and Italy formed and the Confederacy was reabsorbed. This is one engine run. Phone layout and touch comfort were assessed from interface code and generated markup. A live Android Firefox session and the eight-seed balance sweep remain to be measured.
