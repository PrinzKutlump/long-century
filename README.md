# The Long Century

Lead a country from 1836 through 1936 in a single-player historical strategy game. Manage construction, budgets, diplomacy and reform one month at a time. The game runs offline in a browser.

## Play

1. Open [Releases](https://github.com/PrinzKutlump/long-century/releases/latest) and download `long-century.html` from **Assets**.
2. Open the downloaded file in a browser, choose a country and start a campaign. Use **Works** to plan construction and the map to inspect provinces.
3. Keep using the same browser for local saves. Export a save from the game to keep a separate copy.

## Build

Run `python3 build.py` from the repository root. Open `dist/long-century.html` in a browser. Node.js 22 can run the engine tests listed in [tests-quick.txt](tests-quick.txt).
