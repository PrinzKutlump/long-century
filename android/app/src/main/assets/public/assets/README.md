# Asset Expansion Folders (`public/assets/`)

Add new media assets cleanly without size limits:
- `pictures/` — Province illustrations, event art, and leader portraits (`.jpg`, `.webp`, `.png`)
- `audio/` — Era background music tracks & orchestral SFX (`.mp3`, `.ogg`, `.wav`)
- `models/` — Unit/building sprite sheets or 3D GLTF/GLB assets

Register any added paths inside `src/platform/assetManifest.js`.
